# LicitAnalytics

Projeto de Ciência de Dados aplicado às licitações públicas do Município de Riolândia/SP.

O objetivo é analisar dados de processos licitatórios, gerar indicadores por meio de dashboards no Power BI e aplicar modelos de Machine Learning para previsão de valores de futuras licitações.
Atualização: análise de dados de empenhos, liquidações, pagamentos e anulações de despesas entre os anos de 2020 e 2025.

# Tecnologias
- Python;
- Pandas;
- NumPy;
- Power BI;
- Scikit-Learn.

# Funcionalidades
- Unificação das bases de 2020 a 2025;
- Tratamento e limpeza dos dados;
- Cálculo da economia absoluta e percentual;
- Dashboard interativo no Power BI;
- Modelo inicial de regressão linear para previsão de valores;
- Modelo inicial de regressão linear para previsão de economicidade percentual;
- Unificação, tratamento e limpeza dos dados de Despesas de 2020 a 2025;
- Mais dashboard interativas no Power BI relacionadas as Despesas.


# Próximas etapas
- Análise exploratória (EDA);
- Novos indicadores;
- Modelos preditivos para objetos recorrentes (medicamentos, merenda escolar, etc.);
- Comparação entre valores previstos e homologados.
